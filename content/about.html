About SpiritDrop

Hosting,
made effortless.

SpiritDrop delivers ready-to-pour cocktail dispensers to events across our Sydney service area. We prepare the drinks, deliver and set up the dispenser, then return the next day to collect it.

  • 20Ready-to-pour drinks
  • $200Per dispenser
  • Next dayCollection

Why we built
SpiritDrop.

Hosting an event already comes with enough to organise.

We wanted drinks to be one less thing the host had to manage. SpiritDrop was built around a simple service: prepare the cocktails beforehand, deliver them in a dispenser designed to be part of the event, set everything up, and collect the equipment the following day.

The host gets to host.
